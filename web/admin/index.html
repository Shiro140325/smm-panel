Set up your authenticator

  1. Open an authenticator app: Google Authenticator, Microsoft Authenticator, or the Passwords app on iPhone and iPad.
  2. Scan this code with it, or tap Open in authenticator app if the app is on this device.
  3. Type the 6-digit code it shows.

Or enter this key by hand
The authenticator is on. From now on the control panel asks for its code after the password.

Save these backup codes somewhere safe, like your notes or a password manager. Each works once if you lose the device with the app. They won't be shown again.
